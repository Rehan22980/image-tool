# Image Tool & Course Designer

Two browser apps in plain HTML and JavaScript — no install, no server, no build step. Open the files in Chrome or Edge.

## 🖼️ Image Tool — `index.html`

- **Edit:** rotate, flip, crop (free or fixed ratios), brightness / contrast / saturation and other adjustments, filter presets, text watermark
- **Compress:** JPEG / WebP / PNG with a quality slider, or "compress to a target size" (e.g. under 100 KB), before/after comparison
- **Resize:** many widths at once plus social media presets (Instagram, YouTube, Facebook, LinkedIn, favicon…)
- **Background:** remove or replace a plain background by colour
- **Colors:** colour palette of the image and a colour picker
- **Passport:** passport / ID photo sizes (35×45 mm, 2×2 in and more), background change, and a print sheet (4×6, A4, custom paper…) with as many copies as fit, saved at 300 DPI
- **Batch:** compress many images at once

## 🎓 Course Designer — `design.html`

- Drag-and-drop slide editor: text, shapes, tags, emoji, images, layers, alignment, undo/redo
- 10 themes × 5 styles and 20 slide layouts with live previews; restyle the whole deck in one click
- Course details, course and page tags, outline, speaker notes
- Export PNG / JPG / PDF, present full screen, save and open project files
- **AI assistant:** ask for a whole presentation, new slides or improvements — in Urdu, Hindi or English
  - Works free with [Pollinations](https://pollinations.ai) (no key), or with free keys from Google Gemini, Groq or OpenRouter, or Ollama on your own computer
  - 🎤 voice typing (Chrome / Edge) and 📎 picture attachments (Gemini or Groq can read them)
  - Free AI pictures for slides

## Run it

Download the files and double-click `index.html` or `design.html`. The AI features and web fonts need an internet connection; everything else works offline.
